About the Project

How the glossary was developed and checked.

Project purpose

This website was created as a student project to organize essential Translation Studies vocabulary in three languages. It can be used by students who study translation theory, written translation and interpreting.

AI tools used

ChatGPT — initial term selection, draft definitions, examples and translation suggestions.

Web resources — terminology and reference checking.

Development stages

  1. Select a focused topic and collect core terms.
  2. Generate draft translations, definitions and examples with AI.
  3. Compare terminology across English, Kazakh and Russian sources.
  4. Edit inaccurate or unnatural translations manually.
  5. Build the glossary and test navigation.

Sources & Verification

Reference materials used to review terminology and translations.

  • UNESCO Thesaurus — multilingual terminology and subject vocabulary.
  • United Nations Terminology — professional multilingual terminology.
  • IATE — European Union terminology database.
  • Merriam-Webster — English definitions and usage.
  • Cambridge Dictionary — English definitions and examples.
  • AI assistance: ChatGPT was used for drafting and language support; all entries were reviewed and edited before inclusion.
